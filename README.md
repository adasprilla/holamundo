# HolaMundo — Configurador 3D

Configurador paramétrico 3D hecho con Three.js. 
- Ajusta altura, número de secciones y posición
- Exporta a STL y 3DM (local, sin subir nada)
- Proyecto personal de Daniel Asprilla

No solicita contraseñas ni datos personales.

Visor: arrastra para orbitar, rueda para zoom.
